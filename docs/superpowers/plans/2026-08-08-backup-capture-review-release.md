# 错题智库：交付收口实施计划

> 目标：在不破坏离线主流程的前提下，完成灾备、快速收题、复习闭环、打印导出和 Windows 发布。

## 1. 完整本地资料库备份

- 先写失败测试：备份必须包含 SQLite 一致性快照、全部原件和 SHA-256 清单。
- 实现单文件 `.czkbackup` 容器，读取时校验魔数、边界、相对路径和摘要。
- 恢复前自动创建救援备份；完整备份恢复数据库与原件，继续兼容旧 `.sqlite3` 快照。
- 设置页明确区分完整备份与旧格式，并显示恢复后的救援位置。

## 2. 快速收题

- 保留现有全窗口拖放与多文件部分成功反馈。
- 增加非编辑状态下粘贴剪贴板截图，直接落入当前课程待整理箱。
- 对大小、格式和失败状态给出明确反馈，不拦截文本输入框的正常粘贴。

## 3. 复习闭环与打印

- 记录单次复习的四档结果，队列完成后显示本次总结与下一步入口。
- 在既有 Markdown 题目册/答案册之外增加独立、离线、适合 A4 打印的 HTML 文稿。
- HTML 转义全部用户内容，题目册严格不泄露答案。

## 4. 交付验证

- 运行前端全量测试、lint、类型检查、生产构建和 Rust 全量测试。
- 更新版本号、用户文档与变更说明。
- 构建 NSIS 安装包，复制到 `release/` 并计算 SHA-256。
