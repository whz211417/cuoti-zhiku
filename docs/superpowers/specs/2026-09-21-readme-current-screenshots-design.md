# README 当前版本截图设计

## 目标

把 GitHub README 中重复、空状态偏多且不能代表当前版本的四张图片，替换为一组从当前 v0.5.2 前端组件真实渲染、可重复生成、无个人数据的产品截图。

## 展示范围

README 必须覆盖完整学习闭环，而不是只展示资料库和设置：

1. `overview.png`：有真实学习节奏的学习总览，作为 README 主图。
2. `inbox.png`：待整理与拖拽/选择文件入口。
3. `problem-detail.png`：题目、个人作答、答案、解析、错因与知识点同页的题目档案。
4. `ai-review.png`：发送范围确认、模式选择和逐字段建议审核。
5. `review.png`：默认隐藏答案的今日复习阅读页。
6. `knowledge.png`：课程—知识点—题目的知识网络。
7. `materials.png`：课程资料保存、检索与可恢复删除入口。
8. `ai-settings.png`：多平台、模型、能力和凭据设置。

## 生成方式

使用 Playwright 启动系统 Microsoft Edge，打开当前仓库的 Vite 页面，并在页面加载前注入一个仅供截图脚本使用的 Tauri `invoke` 适配器。适配器返回固定的虚构经济学课程、题目、复习与知识网络数据；界面本身仍由当前生产组件、生产样式和真实交互路径渲染。

截图脚本放在 `scripts/capture-readme-screenshots.mjs`，统一使用 1440×900、设备像素比 1、深色主题和减少动画设置。它应自动启动临时 Vite 服务、生成全部八张 PNG，并在结束时关闭浏览器和服务。

## 数据与隐私

- 只使用虚构的宏观经济学、微观经济学与计量经济学示例。
- 不读取本机 SQLite、Windows 凭据管理器、真实教材或 API Key。
- 不显示 Windows 用户名、本地绝对路径、个人课程名或用户导入文件。
- AI 建议只作为演示数据，不宣称由模型实时生成，也不伪造教材引用。

## README 结构

- 顶部主图改为 `overview.png`，让访问者先看到产品整体价值。
- “真实界面”按照“收题 → 整理 → 审核 → 复习 → 连接知识 → 配置能力”的顺序展示。
- 每张图都有具体中文说明；图片不重复，同一行最多两张。
- 保留现有下载入口、本地优先、安全边界和安装说明。

## 验收标准

- 八张 PNG 均为 1440×900，非空、互不重复。
- README 引用八张图片且文件均存在。
- 主图不再是旧的资料录入空状态。
- 图片中无 `C:\\Users`、API Key、真实题目、真实教材或其他个人信息。
- `pnpm test`、`pnpm lint`、`pnpm typecheck`、`pnpm build` 全部通过。
- GitHub 在线 README 可加载所有图片，Latest Release 和推广手册链接仍然有效。
