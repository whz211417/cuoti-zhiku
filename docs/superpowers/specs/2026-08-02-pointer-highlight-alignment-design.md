# 鼠标高光定位修复设计

## 问题

`DynamicControlSurface` 按原始侧栏或工具栏计算鼠标百分比，但 `.dynamic-glass-light` 通过负 `inset` 放大了自身尺寸。相同百分比落在放大后的坐标系中，导致光斑偏离鼠标；侧栏的放大椭圆进一步形成明显的竖向白带。

## 选定方案

动态材质改用相对于宿主表面的像素坐标：

- 每个动画帧读取最新 `getBoundingClientRect()`，用 `clientX - left` 和 `clientY - top` 得到局部坐标。
- 将局部坐标限制在宿主宽高范围内，写入 `--glass-local-x` 和 `--glass-local-y`。
- 高光层与宿主同尺寸，不再使用负 `inset`；光斑以局部坐标为中心绘制。
- 工具栏使用横向、较宽的柔光；侧栏使用更窄的局部光斑，避免照亮整列。
- 鼠标移出时复位到顶部中央并淡出；减少动态或减少透明度时不跟随指针。

## 交互与性能

仍使用单个 `requestAnimationFrame` 合并高频 pointer move。React 不因鼠标移动重新渲染。每帧读取矩形可自动适应滚动、窗口缩放和布局变化，并避免缓存旧矩形造成二次漂移。

## 测试

- 纯函数覆盖局部像素坐标、边界限制和零尺寸回退。
- 组件测试确认最后一次 pointer move 的像素坐标被写入 CSS 变量。
- pointer leave 后确认 inactive 状态与位置复位。
- 减少动态/透明度时确认变量保持静态。
- 聚焦测试、全量前端测试、类型检查、Lint 和生产构建全部通过后重新生成 0.2.0 安装包。

## 范围

只修改动态材质坐标计算、对应 CSS 与测试；不改导航布局、业务功能、AI 流程或数据结构。
