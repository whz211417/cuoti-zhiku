# 错题智库：动态材质设计

## 目标

让本地学习工具拥有清晰的空间层级与自然反馈。动态效果必须帮助用户理解“当前在哪、内容从何而来、操作是否生效”，不能成为持续吸引注意力的装饰。

## 范围

- 主工作台维持实色、稳定、低密度的阅读环境。
- 设置与未来 AI 审核器使用局部玻璃材质；材质只在它们打开时出现。
- 工作台切换、题目打开与返回使用短距离的位置连续动画。
- 按钮、导航和文件条目只提供按压、选中和到达反馈。

## 动效原则

- 进入为 180–300ms 的快速减速；退出更短。
- 通过 opacity、transform 与 filter 合成层动画，避免动画 width、height、布局属性或长距离移动。
- 材质折射参数保持低值：无色散、低弹性、低位移；不使用彩虹光、循环漂浮或果冻回弹。
- 同一时间只允许一个明显的空间过渡。
- `prefers-reduced-motion` 时移除位移与缩放；`prefers-reduced-transparency` 时使用不透明实色表面并停用背景模糊。

## 组件边界

- `App` 负责工作区切换、设置面板开关和导航状态。
- `InspectorSurface` 是材质边界：在透明度降低时改用实色，不向学习页面传播玻璃效果。
- GSAP 只编排工作区容器的进入动画，组件自身的微状态保留在 CSS 中。
- `liquid-glass-react` 只作为 `InspectorSurface` 的视觉实现；不能承载数据逻辑或交互状态。

## 可访问性与验证

- 所有图标按钮保留可见焦点和中文可访问名称。
- 设置面板使用 `role=dialog`、名称和关闭按钮。
- 为导航切换与设置面板保留交互测试；全量测试、生产构建和静态检查必须通过。
