# 错题智库：动态材质设计

## 目标

让本地学习工具具有清晰的空间层级与自然反馈。动效必须帮助用户理解“当前在哪、内容从何而来、操作是否生效”，不能成为持续吸引注意力的装饰。

## 材质层级

- 学习总览、课程书架、最近题目、学习信号、题目档案和复习正文使用不透明实色表面，形成稳定、低密度的阅读环境。
- 侧栏、顶部工具栏与选中镜片属于持续控制层，可使用低强度高光和背景模糊，但不把玻璃扩散到整个页面。
- Spotlight 全局搜索是短暂浮层：背景仅用于降低竞争，搜索表面使用与审核器一致的局部动态材质，关闭后立即退出材质层。
- “今日焦点”是总览中最大的纸张表面，只保留一个系统蓝主操作；统计、课程与活动单元不伪装为玻璃卡片或图表。
- 设置与 AI 审核器使用局部短暂材质，不向学习页面传播玻璃效果。

## 动效原则

- 进入为 180–300ms 的快速减速或临界阻尼弹簧近似，退出更短；不使用线性运动、过度反弹或循环装饰。
- 仅动画 `opacity` 和 `transform`；不动画 `width`、`height`、布局位置或长距离移动。
- 同一时间只允许一个明显的空间过渡。工作区切换、题目打开与 Spotlight 出现保持短距离空间连续性。
- 按钮、导航和文件条目只提供按压、选中和到达反馈；不使用彩色光晕、渐变文字、跑马灯、粒子或滚动计数器。
- 指针跟随只由 `requestAnimationFrame` 批量写入 CSS 自定义属性，不经过 React state，不在连续移动中触发布局测量。

## 组件边界

- `App` 只负责工作区、选中课程与题目、浮层开关和显式刷新令牌，不承载总览聚合或搜索结果状态。
- `LearningDashboard` 是实色内容层；它可根据 `refreshToken` 重新读取，不订阅全局事件。
- `DynamicControlSurface` 是持续控制层边界：只负责合成层高光坐标，不承载业务状态。
- `CommandPalette` 与 `InspectorSurface` 是短暂材质边界；它们的背景降级不得改变搜索、设置或审核语义。

## Web 近似与降级

iOS 26 的光学材质在 Web 中只做性能安全的近似，不声称复制系统级液态玻璃。实现使用原生 CSS 的低强度透明度、模糊、饱和度、边缘高光与合成层位移；不为总览引入新的 GSAP 编排、液态玻璃依赖或逐像素折射。

- 不支持 `backdrop-filter` 时，工具栏、审核器和 Spotlight 直接使用高对比实色纸张与普通边框。
- `prefers-reduced-transparency` 使用不透明表面，停用背景模糊、饱和度和材质高光；遮罩仍保持足够明暗分离。
- `prefers-reduced-motion` 移除位移、缩放、导航弹簧和 Spotlight 展开，内容立即到达最终位置。
- 降级只改变表现，不隐藏操作、不降低文字对比度，不破坏键盘导航。

## 可访问性与验证

- 所有交互目标至少 44×44px，使用语义按钮、中文可访问名称和可见焦点。
- 导航选中态使用 `aria-current`；设置、AI 审核和 Spotlight 使用带名称的模态对话框与明确关闭按钮。
- 桌面双列布局在 900px 以下收拢，780px 以下转为单列并保留四个主导航入口；不得产生水平滚动。
- 发布前覆盖默认、减少动效、减少透明度与窄屏模式，并运行导航、搜索、刷新回调、全量测试、TypeScript 和静态检查。
