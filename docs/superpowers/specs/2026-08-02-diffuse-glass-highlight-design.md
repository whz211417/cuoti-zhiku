# 无轮廓漫反射高光设计

## 背景

现有动态材质已经使用宿主内局部像素坐标，定位准确，但侧栏和工具栏分别绘制了尺寸明确的椭圆径向渐变。用户能够直接看出椭圆轮廓，视觉上更像网页聚光灯或手电筒，而不是玻璃内部的自然光线变化。

视觉对比已确认采用 B「无轮廓漫反射」，不采用单一圆形聚光灯或仅边缘折射。

## 视觉目标

- 鼠标附近的材质只产生轻微、连续的亮度变化。
- 任何时刻都不应看出圆形、椭圆形或硬边光斑。
- 侧栏与工具栏使用同一套光学语言，不再用不同几何形状表达材质。
- 深色模式中不得出现明显白带；浅色模式中不得产生发灰脏块。
- 动态效果保持克制，不遮挡文字、按钮、选中状态和分隔线。

## 选定实现

保留 `DynamicControlSurface` 当前的局部像素坐标与每帧布局读取逻辑。只调整高光渲染：

1. `.dynamic-glass-light` 使用两个错位的圆形径向渐变。
2. 第一层是范围较小的中性高光，中心相对鼠标轻微向左上偏移。
3. 第二层是范围较大的冷色环境光，中心相对鼠标轻微向右下偏移。
4. 两层均使用长距离透明衰减，并在整体图层上增加模糊，使两个圆无法被单独辨认。
5. 图层仍与宿主同尺寸并受宿主 `overflow: hidden` 裁切，不恢复负 `inset`。
6. 删除 `.sidebar .dynamic-glass-light` 和 `.toolbar .dynamic-glass-light` 中的椭圆渐变。两者可以保留轻微的强度差异，但不得改变为可见几何形状。
7. 导航动态材质最大透明度从 `0.32` 降到约 `0.20`，移出时淡出为 `0`。

## 动态与性能

- 鼠标位置继续通过 CSS 自定义属性更新，不触发 React 重渲染。
- 高频移动继续由单个 `requestAnimationFrame` 合并。
- 光斑中心直接跟随鼠标，避免滞后造成定位错觉；仅透明度使用现有弹簧式缓动。
- 不增加 GSAP、Canvas、SVG filter 或新的运行时依赖。
- `will-change` 只保留实际动画属性，避免扩大合成层成本。

## 无障碍降级

- `prefers-reduced-motion: reduce`：高光保持不可见。
- `prefers-reduced-transparency: reduce`：高光元素继续隐藏，控件使用实色材质。
- 不改变键盘焦点、指针命中区域或屏幕阅读器结构。

## 测试与验收

- 新增样式回归测试，要求动态材质包含两层圆形径向渐变。
- 回归测试要求侧栏和工具栏高光规则不包含 `ellipse`。
- 现有局部像素坐标、动画帧合并、布局变化与离开复位测试继续通过。
- 完整前端测试、类型检查、lint 与生产构建必须通过。
- 在本地实际页面中移动鼠标，确认光线中心位于鼠标附近，同时看不到圆形或椭圆轮廓。
- 重新生成 Windows x64 NSIS 安装包并更新字节数与 SHA-256。

## 范围

本次只优化动态导航材质的高光外观及其回归测试，不修改页面布局、颜色系统、数据结构、学习流程、AI 功能或安装版本号。
