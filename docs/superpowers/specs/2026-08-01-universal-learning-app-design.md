# 错题智库：通用学习应用升级设计

## 1. 产品定位

“错题智库”从经济学专业个人工具升级为面向高中生、大学生、考研、考公、语言与职业资格学习者的 Windows 本地学习应用。产品仍聚焦题目、资料、整理与复习，不扩张为泛笔记、团队协作或云盘。

升级必须保留现有本地题库、原件、教材索引、复习计划、备份与导出语义。没有配置 AI 时，导入、编辑、搜索、复习、导出和备份仍完整可用。

## 2. 设计原则

1. 文件比表单先到：用户可以把图片和文件直接拖进应用，不必先寻找上传按钮。
2. 原件先安全保存：文件一旦被接受，先进入本地待整理记录，分类和字段可以稍后补充。
3. AI 是可更换的工具：Provider、模型和 Key 都由用户选择，任何平台故障都不能破坏本地流程。
4. 通用而不空泛：文案不绑定经济学，但“题目—答案—解析—错因—知识点—复习”的核心结构不变。
5. 苹果感来自空间、层级和反馈：不靠满屏透明、廉价渐变或循环动画制造高级感。

## 3. 用户与首日体验

目标用户是需要长期整理学习题目与课程资料的个人学习者。首次打开不显示强制向导，也不填充演示统计。

空白首页只呈现三个真实入口：

- 拖入题目或题图；
- 导入学习资料；
- 新建课程。

窗口级拖放始终可用，手动文件选择保留为键盘用户与无拖放环境的备用方式。第一次成功导入后，用一次性轻提示说明“原件已保存在本机，可以稍后补充题干并加入复习”；提示不阻断操作。

## 4. 全窗口文件拖放

### 4.1 接收范围

应用主窗口任何工作区都接收来自 Windows 文件资源管理器的文件拖放。支持：

- 题目原件：PNG、JPG、JPEG、WebP、PDF；
- 通用文本资料：Markdown、MD、TXT；
- PDF 同时可作为题目原件或课程资料，但全窗口快速拖入默认按题目原件处理。

用户选定方案 A：拖入后不要求先选择类型。所有文件先进入待整理；后续可以在记录内改为课程资料。图片默认标记为题图，PDF 和文本文件保留原始类型信息。

### 4.2 课程归属

- 当前明确选中课程时，拖入文件归入该课程；
- 未选课程时，归入现有“未分类”课程；
- 不根据文件名或 AI 自动猜课程；
- 导入完成后可以批量移动课程。

### 4.3 拖入状态

系统只在检测到真实文件进入窗口时显示覆盖层。覆盖层使用短暂的近似 VisionOS 材质，背景内容轻微压暗和缩小，但仍可辨认当前上下文。

状态顺序：

1. `enter`：覆盖层以 180–240ms 阻尼弹簧出现，显示“松手即可保存到待整理”；
2. `over`：显示文件数量、支持类型与目标课程；
3. `drop`：覆盖层收拢为右上角导入进度浮层；
4. `complete`：显示成功数量、失败数量和“查看待整理”；
5. `leave`：覆盖层快速淡出，不保留空壳。

多文件逐个返回成功或错误，单个失败不回滚其他成功文件。重复原件沿用现有 SHA-256 内容寻址，仍创建独立学习记录。

### 4.4 安全与可访问性

- 只接受 Tauri 提供的本地路径，不接受网页 URL 或剪贴板伪路径；
- 后端继续验证扩展名、MIME、大小和可读性；
- 覆盖层不拦截 Escape，Escape 只取消尚未松手的视觉状态；
- `prefers-reduced-motion` 下只改变透明度；
- `prefers-reduced-transparency` 下使用不透明浅色表面；
- 点击“投进题目”与键盘操作保持原功能。

## 5. 通用信息架构与文案

主导航保持四项：学习总览、待整理、今日复习、全部档案。课程列表仍固定在侧栏。

通用化调整：

- “收件箱”改为更易懂的“待整理”；
- “教材依据”扩展为“学习资料”；
- 经济学示例替换为跨学科示例或不带学科的真实空态；
- 课程创建提供可选类型：学校课程、考试科目、语言、证书、其他；
- 类型只影响图标、默认字段提示和颜色建议，不改变数据权限或 AI 行为；
- 现有课程自动归为“学校课程”，不改名、不丢数据。

课程类型通过新的 `courses.kind` 字段保存，并以数据库迁移增加；字段默认值为 `school`，因此现有课程和旧备份升级后具有确定语义。空白首页的“导入学习资料”使用明确的资料文件选择器；全窗口快速拖入始终遵循方案 A，统一进入待整理，不根据落点改变类型。

## 6. 视觉升级

### 6.1 视觉结构

- 侧栏与顶部工具栏继续承担稳定导航，使用克制的半透明材质；
- 主内容采用书页与桌面文具感的实色表面，减少当前连续卡片边框；
- 今日焦点成为一个清晰的行动舞台，课程、最近题目和学习信号通过分区与排版建立层级；
- 题目详情保持 Apple Books / Notes 式阅读页，不改成 SaaS 表单；
- AI 设置、确认和短暂导入状态使用更明确的悬浮材质，其他区域不扩散玻璃效果。

### 6.2 设计标记

- 系统字体优先，中文正文使用 Windows 可用的 UI 字体回退；
- 4/8px 间距体系，常用点击目标不小于 44px；
- 中性色为主，系统蓝只用于当前选择与主操作；
- 课程颜色仅作为书脊、圆点和小面积语义标记；
- 阴影分为导航浮层、纸面和瞬时弹层三级，不为每个区块单独造卡片；
- 支持浅色与深色主题，深色主题不是简单反相；
- 所有正文和关键图标满足 WCAG AA 对比度。

### 6.3 动效

- 页面切换：220–320ms，临界阻尼或快速减速；
- 导航选择：使用共享几何感的滑动底板，不弹跳；
- 拖放覆盖层：进入柔和，离开更快；
- 按钮按压：轻微缩放与高光位移，不改变布局边界；
- 导入完成：一次性状态收拢，不使用粒子、呼吸或循环发光；
- 只动画 `transform`、`opacity` 和合成层滤镜，避免影响 60fps 的布局动画。

## 7. 多 AI Provider 架构

### 7.1 Provider 类型

内置预设：

- 阿里云百炼；
- DeepSeek；
- 智谱 AI；
- 月之暗面；
- OpenAI；
- 自定义 OpenAI-compatible。

Provider 预设只提供名称、默认 Base URL、鉴权方式、推荐模型和能力提示。所有请求统一走应用后端，不把 API Key 暴露给 WebView。

### 7.2 配置模型

非敏感配置保存到 Tauri Store：

```text
provider_id
display_name
base_url
selected_model
vision_model
supports_vision
request_timeout_seconds
is_enabled
```

API Key 使用 Windows 凭据管理器，账户名按 `ai-provider:{provider_id}` 隔离。旧版 `dashscope-api-key` 首次读取时迁移到百炼 Provider；迁移成功后才删除旧凭据。

题库备份与题目册/答案册导出都不包含 API Key。为避免恢复备份时意外切换账号或端点，Tauri Store 中的 Provider 配置也不进入题库备份；恢复后继续使用当前 Windows 用户已有的本机 AI 配置。需要迁移 AI 配置时，用户在新设备上重新选择 Provider、模型并输入 Key。

每个 Provider 支持：保存、测试连接、设为当前、编辑模型、移除 Key。自定义 Provider 允许填写 Base URL 与模型 ID，但限制为 HTTPS；仅 `localhost` 和 `127.0.0.1` 可在用户明确确认后使用 HTTP。

### 7.3 模型选择

普通模式显示每个平台的推荐模型，并按用途标记：快速、深度、支持图片。高级模式允许输入任意模型 ID。

应用不依赖远端模型列表才能工作，也不自动改用其他模型。测试连接返回：鉴权是否成功、模型是否可调用、图片能力是否已声明。平台不提供可靠模型枚举时，不伪造“自动发现”。

### 7.4 请求适配层

新增统一接口：

```text
AiProviderConfig
AiRequest
AiResponse
AiProviderClient
```

OpenAI-compatible Provider 共享 Chat Completions 请求构造与响应解析；差异通过预设配置和小型适配器处理，不在 UI 中写 Provider 分支。

AI 系统提示改为“中文学习题目整理助手”，不绑定经济学。输出仍只生成可审核字段：题干、标准答案、解析、错因、知识点和可验证引用。任何字段都不会自动覆盖本地内容。

### 7.5 请求前确认

每次调用前展示：

- 当前平台和模型；
- 将发送的题目文本；
- 是否包含原图；
- 允许使用的教材片段数量与来源；
- “仅本次发送”确认按钮。

切换 Provider、模型或 Key 不影响已保存题目。网络错误、余额不足、限流、模型不存在和格式错误分别给出可行动提示。

## 8. 组件与模块边界

前端新增：

- `features/ingest/GlobalFileDrop`：窗口级拖入状态与 Tauri 事件订阅；
- `features/ingest/ImportProgress`：批量导入进度与结果；
- `features/settings/AiProviderSettings`：Provider 列表与当前选择；
- `features/settings/AiProviderEditor`：Key、端点、模型与连接测试；
- `features/onboarding/EmptyLibraryStart`：无演示数据的首日行动区；
- `lib/aiProviders`：前端 DTO、能力标签与推荐模型展示。

Rust 新增或调整：

- `services/ai/providers.rs`：Provider 预设与配置验证；
- `services/ai/client.rs`：统一 OpenAI-compatible 请求；
- `services/credentials.rs`：按 Provider 隔离 Key 与旧凭据迁移；
- `commands/ai.rs`：配置读取、保存、测试连接与运行分析；
- `commands/inbox.rs`：复用现有 `import_files`，不复制导入逻辑。

`App.tsx` 只负责挂载全局拖放层和连接工作区动作，不承担 Provider 业务规则。

## 9. 错误处理与恢复

- 拖入包含不支持格式时，支持文件继续导入，失败项逐条说明原因；
- 导入期间关闭覆盖层不取消已开始的本地保存；
- Provider 配置保存失败时保留表单，不覆盖上次可用配置；
- 测试连接不写入题目、不发送本地教材或图片，只发送最小文本探针；
- AI 请求失败时保留已有建议和本地字段，允许重试或切换 Provider；
- 旧凭据迁移失败时保留旧凭据并显示恢复提示；
- 所有异步结果按当前 Provider、题目和请求代次隔离，迟到响应不能覆盖新选择。

## 10. 测试与验收

### 前端

- 任意工作区拖入单文件和多文件；
- 拖离、取消、重复 enter/leave 与不支持格式；
- 当前课程和未分类课程归属；
- 导入成功、部分失败、全部失败与重试入口；
- 空白首页三个入口及首次轻提示；
- Provider 新建、编辑、选择、移除和连接测试；
- Key 从不回显；
- 模型预设与自定义模型；
- Provider/题目切换后的迟到响应隔离；
- 键盘、焦点、减少动态和减少透明度。

### Rust

- Provider 配置校验和 HTTPS 限制；
- Provider 凭据账户隔离与旧 DashScope Key 迁移；
- 百炼、DeepSeek、智谱、月之暗面、OpenAI-compatible 请求快照；
- 文本与图片请求能力边界；
- 连接测试只发送最小探针；
- 错误分类不泄露 API Key 或完整响应敏感信息；
- 现有本地导入、数据库迁移、复习、备份与导出测试保持通过。

### 桌面验收

- Windows 文件资源管理器拖入图片、PDF、Markdown 与 TXT；
- 1280×720 和 1440×900 无布局溢出；
- 浅色、深色、减少动态、减少透明度均可用；
- 无 AI Key 时完整本地流程可用；
- 至少两种国内 Provider 与一个自定义兼容端点完成真实连接测试；
- 安装升级后原有本地题库和旧百炼 Key 可继续使用。

## 11. 不在本次范围

- 账号、云同步、多人协作；
- Provider 插件市场；
- 自动购买额度或平台代理计费；
- 未经用户确认自动上传；
- 根据文件内容自动决定课程；
- 扫描 PDF 的本地 OCR 引擎；
- 移动端版本；
- 自动更新器与商业代码签名。
