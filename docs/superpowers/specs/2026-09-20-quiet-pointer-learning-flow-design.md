# 安静指针与学习闭环设计

## 目标

把错题智库从“有很多精致表面”收束为一款每天打开都知道下一步、鼠标反馈安静准确、离线也能完整工作的学习工具。

本轮优先解决两个问题：

1. 移除常驻大光圈与导航材质追光叠加造成的视觉噪声、掉帧和光标语义丢失。
2. 补齐“投进题目 → 整理完成 → 进入复习”的显式状态闭环，减少重复点击和错误复习。

## 已批准方向

采用视觉方案 A“静默精确”：

- 恢复 Windows 原生光标，不在全局隐藏箭头、文本光标、拖拽或禁用态光标。
- 删除 `ImmersiveCursor` 常驻光点与 68px halo。
- 侧栏和工具栏不再进行逐帧鼠标追光；材质保持静态，只在具体按钮 hover / press 时出现轻微内高光、边界变化和小幅缩放。
- 动效只使用 opacity 与 transform，交互反馈控制在 120–220ms；减少动态时保留颜色/透明度反馈但取消位移。
- 浅色、深色都使用表面相对色，不靠仅在深色背景可见的蓝色荧光。

## 产品范围

### 1. 完成整理并加入复习

题目详情提供唯一明确的主动作“完成整理并加入复习”。最小条件为：

- 已填写题干；
- 已填写标准答案；
- 有合法课程归属，`未分类` 也是合法课程。

提交必须是本地原子操作：将题目从 `inbox` 改为 `active`，安排首次复习日期，并让对应待整理条目不再出现在待整理列表。解析、错因、个人作答和补充笔记保持可选；不自动调用 AI，也不自动采纳 AI 内容。

条件不足时，界面逐项指出缺少内容；数据库不发生部分写入。重复点击已经完成的题目应安全返回当前状态，不生成重复复习记录。

### 2. 复习准入

复习队列只允许 `active` 题目进入，并要求题干与标准答案非空。待整理题不会因为写了题干就提前进入复习。首次复习日期由“完成整理”动作设置，评分流程只负责后续间隔更新。

### 3. 导入后的自然续接

- 单个文件或剪贴板图片导入成功后，直接打开新建题目的整理页。
- 多文件导入保持所有原件先安全落库，然后打开第一道；整理完成后可继续下一道。
- 导入失败不会丢失已经成功保存的文件；结果仍可从待整理页访问。

### 4. 课程归属可见

“投进题目”附近显示当前保存目标，例如“保存到：宏观经济学”。题目页标题区域显示课程并允许修改；`未分类` 始终是安全兜底，不强迫用户先创建课程。

### 5. 核心入口收束

- “全部档案”页直接提供“导出”，先选择题目册或答案解析册，再选择 Markdown 或打印版；设置中不再作为唯一入口。
- 复习空状态提供“去整理待办”或“投进一道题”。复习中提供“稍后再看”和“结束本次”，不写虚假评分。
- 小屏主导航只保留总览、待整理、复习三个高频入口；知识网络与全部档案进入“更多”，避免第五项换行。
- 首页焦点区只保留一个当前行动和一行说明；路径与统计降为次级信息，不增加新卡片。

## 架构与接口

### 本地命令

新增窄接口 `complete_problem_organization(problem_id, expected_version)`：

- Rust 数据库层在单个事务内重新读取题目、验证版本和最小字段、更新状态与首次复习日期、移除或完成待整理记录。
- 成功返回更新后的 `ProblemDocument`，让前端直接刷新而不是猜测状态。
- 版本冲突返回明确错误，前端重新载入并保留用户已保存的数据。

课程变更继续使用窄命令；若现有接口不支持，只新增 `update_problem_course(problem_id, course_id, expected_version)`，不扩大通用更新命令权限。

### 前端状态

- `ProblemDocument` 管理完成检查、提交中、失败重试和成功状态；完成后通过 `onOrganized(problem)` 通知 `App` 刷新总览与待整理列表。
- 导入组件成功回调统一返回有序的 `problemId[]`；`App` 负责打开第一项并保存剩余队列。
- 复习查询约束落在数据库层，前端空状态只呈现真实结果。
- 指针方案不新增运行时 JavaScript 跟踪器；所有局部反馈由 CSS 的 hover / active / focus-visible 驱动。

## 视觉与动效

- 系统光标始终保留；按钮 hover 只增强 1px 边界和低强度内高光，press 使用 `scale(.98)`，不弹跳。
- 导航材质为静态半透明近似；不使用随指针移动的 radial-gradient、blur 重绘或 `transition: all`。
- 工具栏高度收敛至 56–60px；仅滚动形成层叠时显示阴影。
- 评分区合并为一条分段控制，数字键帽直接放入对应按钮。
- 焦点可见性、44px 点击目标和系统字体保持不变。
- `prefers-reduced-motion` 取消位移和弹簧，但保留立即的颜色、边界和透明度反馈；`prefers-reduced-transparency` 使用实色表面。

## 数据安全与错误处理

- 原件保存仍先于任何整理、OCR 或 AI 行为。
- 完成整理、课程修改和评分均使用版本校验，禁止静默覆盖。
- AI 永远是可选建议，不参与完成整理事务。
- 所有失败保持当前页面和本地数据；提供可理解的重试提示，不自动重复写入。
- 不迁移或删除用户现有题目；已有 `active` 题目保持可复习。

## 非目标

- 不增加账号、云同步、积分、连续打卡、排名或通知。
- 不新增首页卡片、独立“导出中心”或独立“资料中心”。
- 不重写间隔重复算法，不改变 AI 供应商配置与请求范围。
- 不引入新的动效库；现有 GSAP 和 liquid-glass 依赖不扩大使用范围。

## 验收标准

1. 任意页面都保留正确的系统箭头、文本、拖拽和禁用态光标；不存在全局 halo 或导航追光。
2. 浅色和深色下，按钮 hover / press 清晰但不抢夺内容注意力；减少动态/透明设置运行时安全。
3. 填写题干与标准答案后，可以一次完成整理；题目变为 `active`，从待整理消失，并进入首次复习计划。
4. 缺少题干或标准答案时，完成动作失败且不产生部分写入。
5. `inbox` 题目永不进入复习队列；`active` 且内容完整的题目按日期进入。
6. 单题导入成功后直接打开；多题导入可从第一道连续整理，任何成功保存的原件不会因后续失败丢失。
7. 课程归属在导入和题目页可见；错误归类可在本地修改。
8. 档案页可直接导出；复习空状态和进行中都有安全出口；小屏导航不换行。
9. Vitest、Rust tests、lint、typecheck、production build 全部通过；浏览器检查覆盖 1440×900、1024×768 和 780px 以下布局。
