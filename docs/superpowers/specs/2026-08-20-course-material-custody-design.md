# 课程资料原件保全与回收站设计

## 目标

让课程 PDF、讲义与文本资料和题图一样成为可恢复的本地学习资产：导入后保存受管理的原件副本；用户删除资料时进入 30 天回收站；恢复后保留原有资料 ID，使已有 AI 引用可以继续解析。

## 范围与非目标

本阶段只处理课程资料的原件保全、列表状态、移除、恢复和过期清理。不会新增云同步、自动 OCR、整本 PDF 上传、AI 自动分析或修改题目删除策略。扫描 PDF 的按页 OCR 将在原件安全保存完成后单独设计，避免产生未受控的模型调用。

## 方案选择

采用“受管理副本 + 数据库软删除 + 延迟物理清理”。相比仅保存外部路径，它能抵抗用户移动或删除源文件；相比立即永久删除，它允许误删恢复。原始文件副本按 SHA-256 内容寻址保存到应用数据目录的 `materials/`，同一内容只保留一份；课程资料记录保留其逻辑文件名和存储相对路径。

## 数据模型

课程资料增加以下字段：

- `original_relative_path TEXT NULL`：应用受管理原件的相对路径；手动粘贴资料为空。
- `sha256 TEXT NULL`：原件内容哈希；手动粘贴资料为空。
- `byte_size INTEGER NULL`：原件字节数；手动粘贴资料为空。
- `deleted_at TEXT NULL`：进入回收站的 UTC 时间；为空表示正常可用。

读取、检索与 AI 授权查询必须默认过滤 `deleted_at IS NULL`。删除操作只写入 `deleted_at`，不删除文本、片段、引用或原件。恢复操作将其清空。清理操作只处理已删除超过 30 天的资料，并在删除原件前检查是否还有其他资料记录引用相同路径。

## 文件流程

1. 用户选择资料文件。
2. 后端验证扩展名并提取可检索文字；提取失败时不创建数据库资料记录，也不留下副本。
3. 后端将文件复制到 `materials/<sha256 前两位>/<sha256>.<ext>`；复制使用临时文件后原子重命名。
4. 在一个数据库事务中写入课程资料、片段和原件元数据。
5. 若数据库提交失败，下一次启动可安全删除孤立的临时文件；不会影响源文件。

手动粘贴资料不产生原件副本，仍可进入回收站并恢复其文字索引。

## 用户界面

课程资料页分为“当前资料”和“最近删除”。当前资料显示来源类型、导入时间与受管理副本状态。点击删除后显示明确范围：应用本地资料会先进入回收站 30 天，电脑上最初选择的源文件从不删除。

回收站内每项提供“恢复”和“永久删除”。永久删除使用独立确认层，并提示将删除应用副本与本地索引。资料页显示可见的“30 天后自动清理”说明；不加入高频动画。删除与恢复后用短暂状态反馈，支持 `prefers-reduced-motion`。

## 命令边界

- `import_course_material_file(course_id, path) -> CourseMaterial`
- `list_course_materials(course_id, include_deleted) -> Vec<CourseMaterial>`
- `trash_course_material(course_id, material_id) -> ()`
- `restore_course_material(course_id, material_id) -> ()`
- `purge_course_material(course_id, material_id) -> ()`
- `purge_expired_course_materials(now) -> usize`

每个有 `course_id` 的命令都在 SQL 条件中校验课程归属。所有 SQL 使用参数绑定。文件路径永远由后端根据受管理的哈希和扩展名构造，前端不能传入目标路径。

## 错误与恢复

- 原件复制或文本提取失败：不创建资料记录，错误消息不泄漏内部目录。
- 重复导入：创建新资料记录以保留课程语义，但复用同一内容寻址副本。
- 恢复或清理不存在、跨课程的 ID：返回“资料不存在或不属于当前课程”。
- 物理删除失败：保留资料记录与回收站状态，用户可重试，不谎称完成。

## 测试门槛

- Rust：导入保留受管理副本；重复内容仅一份副本；软删除排除检索；恢复恢复检索；清理仅删除过期资料且不删除仍被引用原件。
- React：资料页显示当前/回收站分区；删除不立即调用永久删除；恢复和永久删除均需要准确调用对应命令；错误保留可操作状态。
- 回归：备份与恢复可携带 `materials/` 受管理原件；题目、AI 引用和现有资料迁移正常。

## 取舍

会增加少量本地磁盘占用，但换来教材可追溯、可恢复与脱离原文件位置的可靠性。自动 OCR 不在本阶段实施，因为它涉及页面选择、成本确认和 AI 隐私范围，必须单独验证。
