# 错题智库：学习驾驶舱设计

## 1. 目标

当前版本已经具备收题、整理、AI 审核、课程资料检索、复习、导出与备份流程，但默认主界面只展示投题区与流程提示，无法回答用户每天打开应用时最关心的三个问题：

1. 今天最应该做什么？
2. 哪门课程正在积压？
3. 最近整理到了哪里？

本次升级增加一个由真实本地数据驱动的“学习总览”，并补全全局搜索。它应让主界面更丰富、更有完成度，但不能变成数据后台，也不能用伪造统计填满空间。

## 2. 设计选择

采用“学习驾驶舱 + 课程书房”的混合结构。

- 不采用纯数据仪表盘：它会削弱错题、教材和复习的阅读感。
- 不采用 AI 中心：AI 仍是用户明确同意后才启用的增强功能，不能成为本地流程的入口。
- 学习驾驶舱负责行动优先级，课程书房负责长期沉淀。

设计语言继续使用 iOS 26 启发式 Web 材质近似。玻璃只用于导航、工具栏、快捷操作与短暂浮层；课程、题目、统计正文使用稳定实色表面。

## 3. 信息架构

侧栏增加“学习总览”，并设为应用默认工作区。其余入口保持原名称和职责：

1. 学习总览
2. 收件箱
3. 今日复习
4. 全部档案
5. 课程列表

打开题目档案、设置面板与课程资料库的路径保持不变。用户从总览进入收件箱、复习或题目档案后，可以通过现有侧栏返回。

## 4. 总览布局

总览最大内容宽度与现有工具栏对齐，使用非对称两列布局，不使用等宽统计卡片阵列。

### 4.1 顶部工具栏

- 标题根据时间显示“早上好 / 下午好 / 晚上好”，副标题固定为“学习总览”。
- 保留设置按钮。
- 搜索按钮打开全局搜索浮层。
- 增加“投进题目”主操作，直接调用现有文件选择流程。

### 4.2 今日焦点

页面左上方设置一个主要行动区，按以下优先级选择主提示：

1. 有到期复习题：显示题目数量和“开始复习”。
2. 没有到期复习题但有待整理题：显示数量和“继续整理”。
3. 两者都没有：显示“资料库已整理好”，提供“投进题目”。

同一区域以较小文字显示待整理、到期复习、课程和教材总数。数字必须来自 SQLite 聚合结果；数据为零时显示 0，不使用示例值。

### 4.3 课程书架

显示最多四门未归档课程，每门课程包含：

- 课程名称与颜色；
- 题目总数；
- 待整理数量；
- 到期复习数量；
- 教材数量；
- 最近更新时间。

点击课程会选中侧栏课程并进入课程资料库。课程超过四门时显示“展开全部”，在当前书架内展开其余课程；再次点击可收起，不创建无内容占位卡片。

### 4.4 最近题目

按 `problems.updated_at` 倒序显示最近五条未删除题目。每条包含：

- 题干首行；没有题干时使用原文件名；
- 所属课程；
- 当前阶段“待整理 / 可复习”；
- 相对更新时间。

点击后打开现有题目档案。列表为空时展示投题操作，不展示虚构题目。

### 4.5 学习脉络

从现有字段中聚合两个紧凑列表：

- 高频错因：读取非空 `mistake_reason` 字段，按规范化文本计数，最多五项；
- 高频知识点：读取非空 `notes` 字段，以中文标点、换行和列表符号拆分，去重后计数，最多五项。

它们用于帮助用户发现重复问题，不计算“掌握率”或其他没有可靠依据的分数。数据不足时显示“完成更多题目后会在这里形成脉络”。

### 4.6 七日活动

七日活动只表示“该日是否发生过整理或复习”，不伪造学习时长。

- 整理活动来自 `problems.updated_at`；
- 复习活动来自 `problems.last_reviewed_at`；
- 同一题同一天只计一次；
- 展示最近七天的真实活动次数和今天状态。

## 5. 全局搜索

点击工具栏搜索按钮或按 `Ctrl+K` 打开 Spotlight 风格浮层。

### 5.1 搜索范围

- 题目标题与题干；
- 标准答案、解析、错因和知识点笔记；
- 课程名称；
- 教材文件名与本地材料片段。

### 5.2 交互

- 输入两个字符后开始查询；
- 结果按“题目 / 课程 / 教材”分组，总数最多十二条；
- 键盘上下键移动选择，Enter 打开，Escape 关闭；
- 打开题目进入题目档案；
- 打开课程进入课程资料库；
- 打开教材结果进入资料库并保留查询词；
- 搜索内容和结果不离开本机，不触发 AI。

空查询显示最近题目与快捷入口。无结果时提供“投进题目”和“前往课程资料库”，不自动改写查询。

## 6. 组件边界

前端新增独立功能目录 `src/features/dashboard/`：

- `LearningDashboard`：负责总览组合，不直接调用数据库；
- `TodayFocus`：根据聚合结果选择一个主要行动；
- `CourseShelf`：渲染课程摘要；
- `RecentProblems`：渲染最近题目；
- `LearningSignals`：渲染错因、知识点和七日活动；
- `useDashboardOverview`：加载、重试和刷新总览数据。

前端新增 `src/features/search/`：

- `CommandPalette`：浮层、键盘导航和分组结果；
- `useLibrarySearch`：带防抖的本地查询；
- 搜索状态只存在于浮层内部，不进入全局应用状态。

`App` 只管理当前工作区、选中课程、选中题目和浮层开关。总览的聚合、空状态与错误状态不继续堆入 `App.tsx`。

## 7. 本地数据接口

Rust 侧新增只读命令：

```text
get_dashboard_overview(today)
search_library(query, limit)
```

`get_dashboard_overview` 返回：

- `due_review_count`
- `pending_inbox_count`
- `course_count`
- `material_count`
- `course_summaries`
- `recent_problems`
- `top_mistake_reasons`
- `top_knowledge_topics`
- `activity_last_seven_days`

`search_library` 返回统一结果模型：

- `kind`
- `id`
- `course_id`
- `title`
- `snippet`
- `updated_at`

所有聚合查询使用参数化 SQL。搜索第一版使用 SQLite `LIKE` 和受控结果上限，不引入网络搜索或外部索引。数据规模增长后再评估 FTS5，不在本次范围中提前增加迁移复杂度。

## 8. 刷新与数据流

应用打开时加载一次总览。以下操作成功后刷新总览缓存：

- 新题原件保存完成；
- 题目字段保存完成；
- 复习评分完成；
- 新建课程完成；
- 教材保存完成；
- 资料库恢复完成。

切回“学习总览”时进行一次轻量重新验证。加载过程中保留上一次成功结果，并在相关区域显示低干扰加载状态，避免整个页面闪白。

## 9. 错误与降级

- 总览查询失败时显示一个内联错误区和“重新加载”，侧栏、收题、复习和设置继续可用。
- 搜索失败时只在浮层内显示错误，不关闭浮层。
- 单条记录缺少题干、课程或日期时使用明确的本地回退字段，不导致整组结果失败。
- `prefers-reduced-motion` 时取消入场位移、导航弹簧和搜索浮层缩放。
- `prefers-reduced-transparency` 时总览工具条和搜索浮层使用不透明实色。
- 不因总览功能请求 AI，不要求 API Key，不上传任何记录。

## 10. 动效与视觉约束

- 页面进入使用 220–300ms 的快速减速或临界阻尼弹簧。
- 课程摘要悬停只改变边缘高光和 1px 内的位移。
- 今日焦点的主操作提供按压缩放，禁止循环呼吸、粒子和大幅果冻回弹。
- 搜索浮层从工具栏搜索按钮的空间位置自然展开，关闭动画更短。
- 只动画 `opacity`、`transform` 与合成层滤镜；统计数字变化不使用滚动计数器。
- 主色保持系统蓝，课程颜色只作为小面积语义标记。

## 11. 测试与验收

### Rust

- 空资料库返回全零聚合，不报错；
- 课程摘要计数与课程隔离正确；
- 到期复习只计算 `next_review_at <= today`；
- 最近题目排序与数量上限正确；
- 错因、知识点与七日活动聚合不重复计数；
- 搜索能命中题干、答案、课程和教材；
- 搜索结果受课程与全局上限约束；
- SQL 特殊字符不会破坏查询。

### React

- 应用默认进入学习总览；
- 今日焦点按复习、整理、空资料库顺序选择行动；
- 课程和最近题目可以进入正确工作区；
- 加载、空数据、部分字段缺失和错误状态可见；
- `Ctrl+K`、方向键、Enter 与 Escape 工作；
- 搜索分组与无结果状态正确；
- 总览刷新不会清除当前题目编辑状态。

### 视觉与桌面验收

- 1280×720 与 1440×900 下首屏信息完整且无水平滚动；
- 侧栏、工具栏、总览和搜索浮层层级正确；
- 高对比焦点、键盘导航和中文可访问名称完整；
- 降低动态效果与降低透明度模式可用；
- 指针交互期间不使用 React state 跟踪连续坐标；
- 全量前端测试、Rust 测试、Lint、TypeScript、Clippy、生产构建和 Windows 安装包构建通过。

## 12. 本次不做

- 云同步、账号系统和多人协作；
- 人工智能自动总结首页；
- 学习时长、排名、掌握率等无法可靠推导的指标；
- 复杂图表库、雷达图和伪精确百分比；
- FTS5 索引迁移；
- 改变现有题目字段、AI 审核、备份与导出语义。
