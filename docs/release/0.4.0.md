# 错题智库 0.4.0

发布日期：2026-08-21

## 这一版

- 增加沉浸式应用指针：在桌面端精细指针下提供轻量跟随、交互目标反馈与按下状态；输入框、可编辑文本和无障碍场景保持系统原生光标。
- 深色与浅色界面都保留可见且克制的鼠标反馈，系统减少动态效果设置会自动降低动画。
- 课程资料支持可恢复的本地管理：查看、删除、恢复和清理只作用于应用托管的副本与索引，绝不删除用户原始文件。
- 继续强化 AI 审核流程：建议逐字段处理，保存冲突后可恢复到最新版本继续完成剩余采纳。
