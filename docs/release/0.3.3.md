# 错题智库 0.3.3

- AI 辅助整理改为两阶段流程：先显示本次发送摘要，再生成可审核建议。
- 题图、课程教材片段、平台与模型收进“添加依据”，默认不发送题图与教材。
- 缺少平台或 API Key 时留在当前审核器中说明原因，由用户明确前往设置。
- 新增“采纳全部空白字段”；已有内容只显示为“替换”，不会被批量覆盖。
- 批量采纳逐字段推进文档版本；中途失败时已保存内容保留，剩余建议也不会丢失。
- 采纳遇到版本冲突时自动载入最新题目，保留尚未写入的建议供直接重试。
- 写入期间锁定关闭操作；最后一项采纳或忽略后自动收起，并显示本次写入数量。
- AI 结果与设置弹层共用一个动态视口滚动面，小屏按钮与模式选择自动堆叠。
- 修复窄屏网格把空白高度分配给顶部导航的问题，内容更早进入可视区域。
- 加入克制的弹簧式状态过渡，并完整尊重减少动态效果与减少透明度偏好。
- Rust 测试脚本固定使用项目既有 GNU/MinGW 工具链，避免误用缺少链接器的 MSVC 环境。
