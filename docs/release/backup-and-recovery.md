# 备份与恢复

## 创建备份

在“设置 > 本地资料库备份”选择“创建备份”，保存一个新的 `.sqlite3` 文件。应用使用 SQLite 一致性快照，不会复制正在变化中的半成品数据库。

内置快照包含：

- 课程、题目字段和字段版本
- 教材文本与本地检索片段
- 复习计划和复习状态
- 原件的内容哈希与相对路径记录

内置快照当前不包含：

- `originals` 目录中的题图与 PDF 文件
- Windows 凭据管理器中的 DashScope API Key

若用于迁移电脑，请关闭应用并复制整个 `%LOCALAPPDATA%\com.cuoti.zhiku` 目录，而不是只复制 `.sqlite3` 快照。

## 恢复

1. 在设置中选择“从备份恢复”。
2. 选择由当前版本创建的 `.sqlite3` 快照。
3. 阅读确认信息。确认后，应用先在 `backups` 目录创建当前数据库的救援副本。
4. 应用检查 SQLite 完整性和资料库版本，只有校验通过才替换当前数据库。
5. 恢复完成后应用重新载入资料库。

损坏文件、非错题智库数据库或不兼容版本会被拒绝，不会静默覆盖当前数据。
