# 备份与恢复

## 创建完整备份

在“设置 > 完整本地备份”选择“创建备份”，保存一个新的 `.czkbackup` 文件。它包含：

- SQLite 一致性快照：课程、题目、字段版本、教材索引、复习状态
- `originals` 中的全部题图、PDF、Markdown 与文本原件
- 每个文件的路径、大小与 SHA-256 校验值

应用使用临时文件写入并在完成后更名。目标文件已存在、原件目录包含符号链接、体积超过安全上限或任一文件读取失败时，不会留下一个伪装成功的备份。

API Key 不进入备份。它仍只保存在当前 Windows 用户的凭据管理器中。

## 恢复

1. 在设置中选择“从备份恢复”。
2. 选择 `.czkbackup`；旧版本创建的 `.sqlite3` 快照仍可恢复，但不包含原件。
3. 确认后，应用先在本地 `backups` 目录创建当前资料库的完整救援备份。
4. 完整备份会先验证魔数、清单边界、安全相对路径、全部 SHA-256 与 SQLite 完整性。
5. 验证通过后才替换数据库和原件；中途失败会尽力回滚到恢复前状态。
6. 恢复完成后应用重新载入资料库。

损坏、被篡改、非错题智库或版本不兼容的文件会被拒绝。即使有完整备份，重要资料仍建议保留至少两份，放在不同存储设备。
