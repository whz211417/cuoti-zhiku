# 错题智库 0.3.2

- 设置与 AI 审核浮层改为动态视口内的单一滚动容器，长内容可以完整滚到底。
- 浮层通过根节点 Portal 脱离工作区 stacking context，窄屏顶部导航不再覆盖标题与关闭按钮。
- 玻璃组件只负责视觉材质，应用自身掌控宽高、内边距、裁切和滚动；修复第三方默认 padding 导致的越界。
- 窄屏下表单、分析模式、教材授权与导出操作自动改为单列或紧凑网格，禁止横向溢出。
- 标题栏在滚动过程中固定并使用实色背景，关闭入口始终可达，也兼容减少透明度设置。
- Windows 原生窗口最小尺寸由 1024×680 调整为 760×520，适配高 DPI 缩放和较小工作区。
