# 错题智库 0.5.1

验证日期：2026-09-20

## 这一版

- 取消覆盖全界面的荧光跟随层，恢复 Windows 原生鼠标指针；按钮、导航与输入控件只在交互位置提供克制的悬停、聚焦和按压反馈。
- 导入图片、PDF 或文本后直接打开第一道成功保存的题目，同时保留全部导入结果，失败项仍可在待整理中恢复处理。
- 题目整理新增必填检查、课程选择和“完成整理并加入复习”；只有题干与标准答案齐全、且已完成整理的题目才进入复习计划。
- 今日复习新增“稍后再看”和“结束本次”，不会把跳过误记为评分；评分键盘提示合并到分段控件中。
- 题目档案页增加直接可见的“导出题册”，搜索浮层支持点击背景关闭。
- 小屏导航精简为学习总览、待整理、今日复习和“更多”，760 像素宽度下不再出现五项拥挤或横向溢出。

## 验证记录

- `npm.cmd test`：34 个测试文件、227 项测试通过。
- `npm.cmd run test:rust`：108 项测试通过；仅保留两个与本次修改无关的既有 dead-code 警告。
- `npm.cmd run lint`、`npm.cmd run typecheck`、`npm.cmd run build`：全部通过。
- Chrome 实际渲染检查：1440×900、1024×768、760×900 均无横向溢出；760 像素下次级导航收进“更多”。
- 原生指针语义检查：页面使用系统默认指针，按钮使用 pointer，不再安装全局 pointermove 跟踪。
- `prefers-reduced-motion: reduce`：媒体查询生效，装饰动画按系统偏好降级。
