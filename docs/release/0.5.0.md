# 错题智库 0.5.0

发布日期：2026-08-24

## 这一版

- 学习总览现在只突出当前最值得做的一步：优先复习、再整理、然后继续上一道题或投进新题，减少在多个入口之间判断的负担。
- 专注复习页显示本次位置与进度；`Space` 显示答案，`1` 至 `4` 快速记录“忘记、困难、熟悉、掌握”。输入、组合键、长按和保存中不会误触。
- 进度和路径在小窗口中自动收束；系统启用“减少动态效果”时，新增过渡会立即降级。
