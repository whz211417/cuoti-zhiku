# 错题智库 0.3.0

- 新增课程知识网络：课程、知识点与题目关系可缩放浏览，并按薄弱程度筛选。
- 新增 Obsidian 安全导出：Markdown、附件、课程 Canvas 与同步清单；用户改动不会被静默覆盖。
- 备份升级为 `.czkbackup` 单文件完整灾备，包含数据库、全部原件和逐项 SHA-256。
- 支持在非编辑区域直接粘贴剪贴板截图，沿用现有内容地址与去重规则。
- 复习队列完成后显示本轮四档评分与最早下一次复习日期。
- 题目册与答案解析册新增离线 A4 HTML 打印版，题目版继续严格排除答案字段。
- 延续主工作台、阅读页和短暂玻璃浮层的分层设计，并覆盖深色、减少动态与减少透明度。
