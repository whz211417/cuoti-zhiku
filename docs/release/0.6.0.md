# 错题智库 0.6.0 · 整理与找回

右键或点击行末的「⋯」，就能在待整理、题目档案和课程资料中移除不需要的内容。每次移除前都会确认。

- **题目可以找回。** 在「全部档案 → 最近删除」恢复，课程、关联原件、答案和复习进度随题目一起回来。题目在恢复前不出现在搜索、复习、知识网络和导出中，不会自动清空。
- **课程资料保留原有 30 天找回期限。** 移除只影响应用内副本，资源管理器里的导入源文件不会被删除。
- **兼顾键盘操作和小窗口。** 行末菜单可用键盘打开和选择，`Esc` 可以取消；靠近窗口边缘时菜单会自动调整位置。
- **深色模式下的整理提示更清楚。** 待整理旁的流程提示使用与系统主题一致的背景。
- **升级保留学习记录。** 资料库从架构版本 7 升至 8、保留已有记录。升级前可在设置创建完整备份。

Windows 安装包、SHA-256 和更新签名以 [GitHub Releases](https://github.com/whz211417/cuoti-zhiku/releases) 上已公开的资产为准。参见 [安装与校验](windows-installation.md)。
