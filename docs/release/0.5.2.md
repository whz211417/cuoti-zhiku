# 错题智库 0.5.2

这是“安装一次，日常直接打开”的 Windows 交付版本。

## 本次改进

- 新增“关于与更新”：在应用内检查版本、阅读更新说明并查看下载进度。
- 更新必须由用户明确确认；断网或检查失败不会影响本地学习流程。
- 正在编辑或保存题目时禁止安装，避免更新中断未保存内容。
- 使用固定公钥校验更新签名，更新地址仅允许 GitHub Releases HTTPS 端点。
- 发布标签会自动执行前端、Rust、类型和规范检查，生成草稿 Release、安装包、更新签名、`latest.json` 与 SHA-256。

## 使用方式

首次安装后，从桌面或开始菜单打开“错题智库”，无需反复运行安装包。后续版本可在“设置 → 关于与更新”中检查；离线安装、修复或迁移电脑时才需要重新使用安装包。

## 数据安全

升级不会主动删除 `%LOCALAPPDATA%\com.cuoti.zhiku`。发布前仍需完成一次真实安装、启动、资料保留和更新检查验收；GitHub Release 默认保持草稿，验收后才公开。
