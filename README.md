# 错题智库

面向中文大学生的 Windows 本地错题学习应用。题图和 PDF 会先保存到本机，再在同一份题目档案中补充题干、作答、答案、解析与错因。

## 当前可用流程

1. 新建课程或使用“未分类”。
2. 投入 PNG、JPG、WebP 或 PDF；原件以 SHA-256 内容地址安全保存在本地。
3. 重启应用后，收件箱仍保留待整理记录；重复原件不会重复占用存储。
4. 打开题目档案，编辑题干、作答、标准答案、解析、错因和笔记。
5. 字段保存使用版本保护，避免旧页面覆盖新编辑。
6. 使用专注复习阅读页主动揭示答案；间隔算法在本地确定性计算。

## 隐私与 AI

核心收题、整理、课程和复习流程不需要网络或 API Key。AI 仍是后续可选增强：在它上线前，应用不会假装完成识别、答案或教材引用。

## 开发与验证

```powershell
pnpm test
pnpm build
```

Windows 安装包由 Tauri NSIS 目标生成。首次打包需要安装 Rust Windows 工具链和 Visual C++ Build Tools，或使用已配置的 GNU/MinGW 工具链。

## 本地数据

发布版的数据库与原件保存在 Windows 的应用本地数据目录中。请在升级前或重要资料录入后自行复制该目录；内置备份与恢复将在后续版本加入。
